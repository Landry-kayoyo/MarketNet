# MARKETNET — Parcours utilisateurs

## Client visiteur (sans compte)
Accueil → recherche/catégorie → produit ou boutique → consultation → panier → coordonnées de livraison → commande invitée → transmission au commerçant via WhatsApp. Aucune inscription ni connexion client n’est demandée.

## Produit
Produit → galerie → informations → variante/quantité → panier → coordonnées client → commande invitée → WhatsApp du commerçant. Aucun compte client n’est requis.

## Boutique
Marketplace → boutique → recherche/catégorie → produit → contact.

## Commerçant
Connexion → tableau de bord → produits, commandes, messages, analytics, personnalisation, paramètres → boutique publique.

## Administrateur
Connexion → gestion des utilisateurs, commerçants, boutiques, produits, contenus, signalements et paramètres selon les permissions.
