# MARKETNET — Spécification API

## Domaines
Authentification, utilisateurs, boutiques, produits, catégories, panier et commandes, messages, avis, analytics et administration.

## Chaque endpoint doit préciser
Méthode, route, authentification, permission, paramètres, requête, réponse, erreurs et codes HTTP.

## Principes
Validation serveur, réponses cohérentes, erreurs structurées, protection des données sensibles, pagination et filtres lorsque nécessaires, versionnement si nécessaire.

## Règle
Les routes exactes sont définies dans l’architecture et ne doivent pas être inventées arbitrairement par un agent.
